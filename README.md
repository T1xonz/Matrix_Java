# Complex Matrix Calculator

Консольный калькулятор для работы с матрицами комплексных чисел: сложение, умножение, деление, транспонирование и вычисление определителя.

## Возможности

- Собственный класс `Complex` для арифметики комплексных чисел (сложение, вычитание, умножение, деление)
- Класс `ComplexMatrix` с операциями над матрицами:
  - сложение (`+`)
  - умножение (`*`)
  - деление (`A / B = A * B⁻¹`)
  - транспонирование
  - определитель 
  - обратная матрица
- Консольный интерфейс: создание матриц, выбор операции, хранение результатов в памяти сессии
- Понятные сообщения об ошибках (несовпадение размеров, деление на ноль, вырожденная матрица)

## Сборка и запуск

```bash
javac Complex.java ComplexMatrix.java Main.java
java Main
```

## Формат ввода чисел

Комплексные числа вводятся без пробелов внутри самого числа, например:

| Ввод      | Значение     |
|-----------|--------------|
| `3`       | 3            |
| `-2.5`    | -2.5         |
| `i`       | 0 + 1i       |
| `-i`      | 0 - 1i       |
| `2i`      | 0 + 2i       |
| `1+2i`    | 1 + 2i       |
| `1.5-3i`  | 1.5 - 3i     |

Элементы строки матрицы разделяются пробелами.

## Пример сеанса

```
=== Калькулятор матриц комплексных чисел ===

1 - Создать матрицу
2 - Показать все матрицы
3 - Сложить (A + B)
4 - Умножить (A * B)
5 - Разделить (A / B)
6 - Транспонировать
7 - Определитель
0 - Выход
> 1
Имя матрицы (например, A): A
Число строк: 2
Число столбцов: 2
Вводите строки: 2 чисел через пробел, формат: 3, -2.5, i, 2i, 1+2i, 1.5-3i
Строка 1: 1+i 2
Строка 2: 3 4-i
Матрица A сохранена.

> 7
Имя матрицы: A
Определитель = -1+3i
```

Результат любой операции (сложение, умножение, деление, транспонирование) автоматически сохраняется под именем `R` и может использоваться как операнд в следующей операции.
